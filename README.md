# PureFlow Next.js Component-Based Project

Next.js App Router + TypeScript + reusable components. No backend/database is included; localStorage makes the demo flows functional.

## Run

npm install
npm run dev

## Routes

/ /products /cart /checkout /track-order /login /signup /account /faq /about /contact /admin/login /admin

## Admin demo

admin@pureflow.local / admin123

## Architecture

- app/: routing via Next.js App Router
- components/: reusable UI/pages/components
- lib/: shared types
- data/: seed data
- public/: future assets

The UI is designed to be extended later with API/database services.
